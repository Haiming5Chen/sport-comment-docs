# Run the Application Locally

## Audience

Entry-level developers who want to test the Sport Comment Web Application on their local machine.

## Purpose

Running the application locally allows developers to test features, debug issues, and verify functionality before deployment.

## Prerequisites

Before running the application, make sure you have already completed the following:

- Set up the development environment
- Installed all project dependencies
- Configured the `.env.local` file with required API keys

## Steps

```bash
# Step 1: Navigate to the project directory
cd <project-folder-name>

# Step 2: Start the development server
npm run dev

# Step 3: Open the application in your browser
# Replace the port if your configuration uses a different one
http://localhost:3000
```

## Result

If the application runs successfully:

- The development server starts without errors
- The terminal shows the server status
- The homepage loads in the browser
- The frontend connects to backend services and APIs
