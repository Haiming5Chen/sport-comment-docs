# FAQ

## About Game and Player Information

### Why are there no players listed for a game?

If a game does not display any players, it usually means one of the following:

- The game has not started yet
- The game is currently ongoing, and official player data has not been finalized

Player statistics usually become available as the game progresses or after it finishes.

---

### The game is already over. Why are there still no players shown?

Player data is retrieved from an external sports API.

After a game ends, it may take a few minutes for the API provider to update the player statistics.

The system refreshes data approximately every **3 minutes**.  
If players are not visible immediately after a game ends, wait a few minutes and refresh the page.

---

## Navigation

### How do I go back to the game page from the comment page?

On the comment page, look for the **hovering score window near the game badge**.

Click the section displaying the **team names and score**.  
This action returns you to the main game page.

---

## Searching and Viewing Games

### How can I search for upcoming games?

Currently, the system only displays **today’s games**.

Upcoming games beyond today are not searchable in this version of the application.

Future versions may include a broader date selection feature.

---

## Account and Access

### Is there a guest mode?

No. The application does **not support guest mode**.

You must log in to:

- Post comments
- Interact with other users
- Access personalized features

Users who are not logged in may still have limited access to view content.
