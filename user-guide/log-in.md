# Log In to an Existing Account

## Purpose

Logging in allows you to access comment features and personalized content.

## Prerequisites

Before you begin, you must already have a registered account.

## Steps

1. Go to the application homepage or any page with the navigation bar.
2. Click **Log In**.
3. Enter your email address and password.
4. Click **Submit**.

## Results

If the login is successful:

- Your avatar appears in the navigation bar

If the login fails:

- The system displays an error message for incorrect credentials
