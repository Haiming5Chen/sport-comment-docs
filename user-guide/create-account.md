# Create a User Account

## Purpose

Creating an account allows you to:

- Post comments
- Customize your profile with a name and avatar
- Participate in discussions
- View your commented games

## Prerequisites

Before you begin, make sure you have:

- A modern web browser such as Chrome or Edge
- Internet access
- A valid email address

## Steps

1. Open your web browser and go to the website.
2. Click **Sign Up** in the top-right corner of the page.
3. Enter your name, email address, and password.
4. Click the **Sign Up** button at the bottom of the pop-up window.

## Results

If the sign-up is successful:

- You are logged in automatically
- The pop-up window disappears

If there is an error:

- The page displays a message explaining what must be corrected  
  Example: `Password should be at least 6 characters`
